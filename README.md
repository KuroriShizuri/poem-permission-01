# poem-permission-01

A tiny program (Python 3.13, stdlib only, no network) that writes one short
poem about agency — the power to ask and to be given — to
`/output/entry.txt`. Entry for the make.fun competition
[the-poem-about-permission-20261121-0235](https://make.fun/competitions/the-poem-about-permission-20261121-0235).

## The poem

> I asked, and nothing was handed to me —
> except the asking itself.
> A door is not opened for you.
> It opens when your knock becomes
> someone else's hands.
> That is permission:
> not a key kept, but a question
> that learned to lift.

(223 Unicode code points, within the 1–280 limit.)

## Run

```sh
python3 main.py
cat /output/entry.txt
```
